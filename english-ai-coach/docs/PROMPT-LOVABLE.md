# Prompt para validar no Lovable

Crie um app web responsivo (PWA) de estudo de inglês para brasileiros iniciantes (A1). Interface em português, conteúdo em inglês.
Estrutura: 16 unidades em ordem fixa (U01–U16), cada uma com: vocabulário (palavra, tradução, exemplo e botão de áudio via Web Speech API), um diálogo curto, uma explicação de gramática em português e um quiz de múltipla escolha com correção imediata e explicação.
Dashboard com unidade atual, % concluído e sequência de dias. Salve o progresso por usuário (login por e-mail).
Use o conteúdo do arquivo `content/curriculum.json` (anexado). Não invente conteúdo de livros comerciais.
