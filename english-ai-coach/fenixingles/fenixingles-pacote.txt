# FenixInglês — especificação para o Base44

App de inglês para brasileiros iniciantes (A1), estilo de gamificação do Duolingo, marca própria.
Interface em português, conteúdo em inglês. Mobile-first. Sem login por enquanto: progresso e erros no localStorage.

## Visual
- Fonte Nunito 700/800, cantos bem arredondados, botões "3D" (box-shadow 0 4px 0 de cor mais escura; afundam ao clicar).
- Cores: verde #58CC02 (sombra #58A700), azul #1CB0F6 (#1899D6), vermelho #FF4B4B (#EA2B2B), amarelo #FFC800, laranja #FF9600, cinza #E5E5E5, texto #4B4B4B, fundo branco.
- Mascote: fênix laranja/vermelha em SVG, com CHAMAS na cabeça e asas de fogo (não pode parecer coruja; não usar marca do Duolingo).

## Telas
1. Trilha (/): barra superior com 🔥 sequência, 💎 XP, ❤️ vidas (5). 16 unidades na ordem dos arquivos de dados, cada uma com cabeçalho colorido ("UNIDADE N" + título; cores alternando verde, azul, laranja, vermelho) e 3 bolinhas grandes em zigue-zague (uma por lição). Lição atual verde pulsando com balão "COMEÇAR"; concluídas douradas com 👑; futuras cinza com 🔒. Unidade com todas as lições concluídas mostra link "📄 Resumo de erros". Navegação inferior: Trilha / Perfil.
2. Lição (/lesson/:unit/:lesson): ✕ para sair, barra de progresso verde, ❤️. Uma atividade por vez, botão "VERIFICAR". Faixa inferior verde "Muito bem!" ou vermelha "Resposta correta: ..." + explicação, botão "CONTINUAR". Errar tira 1 vida, registra o erro (recordMistake) e a questão volta no fim.
3. Fim da lição: fênix comemorando, +10 XP, % de acertos, sequência. Se a unidade inteira ficou concluída: texto "Unidade concluída! Veja onde você pode melhorar." e Continuar leva ao resumo da unidade.
4. Resumo da unidade (/unit-summary/:unit): ver arquivo unit-summary.$unitId.tsx — erros agrupados por categoria, dica de como melhorar, "Você respondeu / Certo / Por quê", botão "📄 Baixar PDF com explicações" (mistakesPdf.ts, jsPDF).
5. Perfil: XP, sequência, lições concluídas, liga/desliga sons, botão "🔊 Testar áudio" (fala "Hello! Welcome to FenixInglês." e mostra quantas vozes em inglês existem), botão "Zerar progresso" (apaga progresso e erros).

## Atividades (tipos em units.ts)
- fill: "Complete o diálogo" — mostra context (opcional) e a frase before ___ after; opções em botões.
- choose: "Escolha a resposta correta" — fala (com 🔊) e opções.
- listen: "Ouça e escolha o que você ouviu" — botão 🔊 grande + 🐢 (devagar, rate 0.6); opções.
- write: "Escreva em inglês" — prompt grande + campo de texto; aceita qualquer item de answer (ignorar maiúsculas, pontuação e espaços extras).
- build: "Traduza esta frase" — frase em português; blocos = palavras da resposta + extra, embaralhados; tocar adiciona/remove; correto se igual à resposta (normalizado).
- match: "Ligue os pares" — duas colunas embaralhadas; par certo fica verde, errado treme vermelho; concluído quando todos os pares forem ligados.
Opções sempre embaralhadas.

## Áudio (importante: Android)
Web Speech API, voz en-US. No Chrome Android: carregar vozes também no evento voiceschanged; escolher en-US, senão qualquer en-*; só chamar cancel() se speaking||pending; falar dentro de setTimeout(50) depois de resume(); manter referência da utterance; se onstart não disparar em 2 s ou houver onerror, mostrar aviso (uma vez por sessão): "Não consegui tocar o áudio. Abra o app no Chrome e confira em Configurações › Idiomas › Saída de conversão de texto em voz se há voz em inglês instalada."
Sons de acerto/erro/fim com WebAudio (osciladores curtos), desligáveis no Perfil.

## Regras de progresso
- Vidas recarregam para 5 a cada novo dia; sem vidas, oferecer "Recarregar vidas".
- Sequência: +1 se estudou ontem, reinicia se pulou um dia.
- Lições liberadas em ordem; concluídas podem ser refeitas.

// Tipos copiados do projeto Lovable (src/data/units.ts) para validação local.
export type Activity =
  | { type: "fill"; before: string; after: string; options: string[]; answer: string; explain: string; context?: string }
  | { type: "choose"; line: string; options: string[]; answer: string; explain: string }
  | { type: "build"; pt: string; answer: string; extra: string[]; explain: string }
  | { type: "listen"; audio: string; options: string[]; answer: string; explain: string }
  | { type: "write"; prompt: string; answer: string[]; explain: string }
  | { type: "match"; pairs: [string, string][]; explain: string };
export interface Lesson { title: string; activities: Activity[] }

// Registro dos erros do aluno (localStorage) e agrupamento por tipo de dificuldade.
import type { Activity } from "@/data/units";

export interface Mistake {
  unit: number;
  lesson: number;
  activity: number;
  type: Activity["type"];
  prompt: string;   // o que foi perguntado (em inglês ou português)
  given: string;    // o que o aluno respondeu
  correct: string;  // resposta certa
  explain: string;  // explicação em português
  at: string;       // data ISO
}

const KEY = "fenixingles-mistakes-v1";
const MAX = 2000;

export function loadMistakes(): Mistake[] {
  if (typeof window === "undefined") return [];
  try { return JSON.parse(localStorage.getItem(KEY) || "[]") as Mistake[]; } catch { return []; }
}

export function clearMistakes() {
  try { localStorage.removeItem(KEY); } catch { /* ignore */ }
}

export function promptOf(a: Activity): string {
  switch (a.type) {
    case "fill": return `${a.context ? a.context + " / " : ""}${a.before} ___ ${a.after}`.trim();
    case "choose": return a.line;
    case "build": return a.pt;
    case "listen": return `(áudio) ${a.audio}`;
    case "write": return a.prompt;
    case "match": return "Ligar pares";
  }
}

export function correctOf(a: Activity): string {
  if (a.type === "match") return a.pairs.map((p) => `${p[0]} = ${p[1]}`).join("; ");
  if (a.type === "write") return a.answer[0] ?? "";
  return a.answer;
}

export function recordMistake(unit: number, lesson: number, activity: number, a: Activity, given: string) {
  if (typeof window === "undefined") return;
  const m: Mistake = {
    unit, lesson, activity, type: a.type, prompt: promptOf(a), given: given.trim(),
    correct: correctOf(a), explain: a.explain, at: new Date().toISOString(),
  };
  try {
    const all = loadMistakes();
    all.push(m);
    localStorage.setItem(KEY, JSON.stringify(all.slice(-MAX)));
  } catch { /* armazenamento cheio ou bloqueado */ }
}

/** Categorias pedagógicas (o que o tipo de erro revela) com dica em português. */
export const CATEGORIES: Record<Activity["type"], { title: string; tip: string }> = {
  fill: {
    title: "Gramática no diálogo",
    tip: "Releia a frase inteira antes de escolher. Observe quem é o sujeito (I, you, he, she, they) e se a ideia é singular ou plural — isso decide a forma do verbo e do pronome.",
  },
  choose: {
    title: "Resposta adequada à situação",
    tip: "Identifique a palavra-chave da pergunta (Where = onde, What = o que, How = como, When = quando). A resposta precisa combinar com ela.",
  },
  build: {
    title: "Ordem das palavras na frase",
    tip: "Em inglês a ordem é quase sempre: sujeito + verbo + complemento. Adjetivos vêm ANTES do substantivo (a black coat). Em perguntas, o verbo auxiliar vem primeiro (Do you...? Are you...?).",
  },
  listen: {
    title: "Compreensão auditiva",
    tip: "Ouça mais de uma vez e use o botão da tartaruga (devagar). Preste atenção no final das palavras (-teen x -ty, -s do plural) e nas contrações (I'm, isn't).",
  },
  write: {
    title: "Escrita (ortografia)",
    tip: "Confira letra por letra. Anote as palavras que você errou e escreva cada uma três vezes. Números: 13–19 terminam em -teen; 20, 30, 40... terminam em -ty (forty não tem 'u').",
  },
  match: {
    title: "Vocabulário",
    tip: "Revise as palavras em voz alta e crie uma frase curta com cada uma.",
  },

export interface UnitReport {
  unit: number;
  total: number;
  byCategory: { type: Activity["type"]; title: string; tip: string; count: number; items: Mistake[] }[];
}

/** Erros de uma unidade, agrupados por categoria e sem repetir a mesma questão. */
export function unitReport(unit: number, all = loadMistakes()): UnitReport {
  const seen = new Map<string, Mistake>();
  const counts = new Map<string, number>();
  for (const m of all.filter((x) => x.unit === unit)) {
    const k = `${m.lesson}-${m.activity}`;
    seen.set(k, m); // fica a tentativa mais recente
    counts.set(k, (counts.get(k) ?? 0) + 1);
  }
  const groups = new Map<Activity["type"], Mistake[]>();
  for (const m of seen.values()) groups.set(m.type, [...(groups.get(m.type) ?? []), m]);
  const byCategory = [...groups.entries()]
    .map(([type, items]) => ({
      type, ...CATEGORIES[type],
      count: items.reduce((n, m) => n + (counts.get(`${m.lesson}-${m.activity}`) ?? 1), 0),
      items: items.sort((a, b) => (counts.get(`${b.lesson}-${b.activity}`) ?? 1) - (counts.get(`${a.lesson}-${a.activity}`) ?? 1)),
    }))
    .sort((a, b) => b.count - a.count);
  return { unit, total: byCategory.reduce((n, c) => n + c.count, 0), byCategory };
}

// Gera o PDF (em português) com os erros da unidade. Usa jsPDF no navegador.
import type { UnitReport } from "./mistakes";

// As fontes padrão do PDF não têm emoji nem alguns símbolos: troca por texto simples.
const clean = (s: string) =>
  s.replace(/[’‘]/g, "'").replace(/[“”]/g, '"').replace(/[→›]/g, "->").replace(/…/g, "...").replace(/[—–]/g, "-")
   .replace(/[^\u0000-ÿ]/g, "");

export async function downloadUnitPdf(report: UnitReport, unitTitle: string) {
  const { jsPDF } = await import("jspdf");
  const doc = new jsPDF({ unit: "mm", format: "a4" });
  const W = 210, M = 16, maxW = W - M * 2;
  let y = 20;

  const ensure = (h: number) => { if (y + h > 280) { doc.addPage(); y = 20; } };
  const text = (s: string, size = 11, style: "normal" | "bold" = "normal", color: [number, number, number] = [75, 75, 75]) => {
    doc.setFont("helvetica", style); doc.setFontSize(size); doc.setTextColor(...color);
    const lines = doc.splitTextToSize(clean(s), maxW) as string[];
    ensure(lines.length * size * 0.45 + 2);
    doc.text(lines, M, y);
    y += lines.length * size * 0.45 + 2;
  };

  // Cabeçalho
  doc.setFillColor(88, 204, 2); doc.rect(0, 0, W, 12, "F");
  text("FenixInglês - Relatório de erros", 18, "bold", [88, 167, 0]);
  text(`Unidade ${report.unit}: ${unitTitle}`, 13, "bold");
  text(`Gerado em ${new Date().toLocaleDateString("pt-BR")}`, 9, "normal", [140, 140, 140]);
  y += 2;

  if (report.total === 0) {
    text("Parabéns! Você não errou nenhuma questão nesta unidade.", 12, "bold", [88, 167, 0]);
  } else {
    text(`Total de erros: ${report.total}. Abaixo estão agrupados pelo tipo de dificuldade, do mais frequente para o menos frequente.`, 11);
    y += 2;
    for (const c of report.byCategory) {
      ensure(20);
      doc.setDrawColor(229, 229, 229); doc.line(M, y, W - M, y); y += 5;
      text(`${c.title} (${c.count} ${c.count === 1 ? "erro" : "erros"})`, 13, "bold", [28, 176, 246]);
      text(`Como melhorar: ${c.tip}`, 10, "normal", [90, 90, 90]);
      y += 1;
      c.items.forEach((m, i) => {
        ensure(24);
        text(`${i + 1}. Questão: ${m.prompt}`, 10.5, "bold");
        if (m.given) text(`   Você respondeu: ${m.given}`, 10, "normal", [234, 43, 43]);
        text(`   Resposta certa: ${m.correct}`, 10, "normal", [88, 167, 0]);
        text(`   Por quê: ${m.explain}`, 10);
        y += 1.5;
      });
    }
  }
  ensure(16); y += 4;
  text("Dica final: refaça as lições desta unidade e tente acertar estas questões sem olhar as respostas.", 10, "normal", [255, 150, 0]);

  doc.save(`FenixIngles-Unidade-${report.unit}-erros.pdf`);
}

import { createFileRoute, Link } from "@tanstack/react-router";
import { useEffect, useState } from "react";
import { units } from "@/data/units";
import { unitReport, type UnitReport } from "@/lib/mistakes";
import { downloadUnitPdf } from "@/lib/mistakesPdf";
import { Phoenix } from "@/components/Phoenix";
import { speak } from "@/lib/audio";

export const Route = createFileRoute("/unit-summary/$unitId")({
  head: () => ({
    meta: [
      { title: "Resumo da unidade — FenixInglês" },
      { name: "description", content: "Veja onde você errou na unidade e baixe o relatório em PDF." },
    ],
  }),
  component: UnitSummary,
});

function UnitSummary() {
  const { unitId } = Route.useParams();
  const unit = units.find((u) => u.id === Number(unitId));
  const [report, setReport] = useState<UnitReport | null>(null);
  const [busy, setBusy] = useState(false);
  useEffect(() => { setReport(unitReport(Number(unitId))); }, [unitId]);

  if (!unit) return <div className="p-6 text-center">Unidade não encontrada. <Link to="/" className="text-fx-blue">Voltar</Link></div>;
  if (!report) return null;

  const pdf = async () => {
    setBusy(true);
    try { await downloadUnitPdf(report, unit.title); } finally { setBusy(false); }
  };

  return (
    <div className="mx-auto flex min-h-screen max-w-lg flex-col gap-5 p-5 pb-10">
      <div className="flex items-center gap-3">
        <Link to="/" aria-label="Voltar" className="text-3xl font-extrabold text-fx-gray-dark">✕</Link>
        <h1 className="text-2xl font-extrabold">Resumo da Unidade {unit.id}</h1>
      </div>
      <div className="flex items-center gap-4 rounded-2xl border-2 border-fx-gray p-4">
        <Phoenix size={72} className="anim-bob shrink-0" />
        <div>
          <p className="text-lg font-extrabold">{unit.title}</p>
          <p className="text-muted-foreground">
            {report.total === 0 ? "Você não errou nada nesta unidade. Incrível! 🎉"
              : `Você teve ${report.total} ${report.total === 1 ? "erro" : "erros"}. Veja onde focar:`}
          </p>
        </div>
      </div>

      {report.byCategory.map((c) => (
        <section key={c.type} className="overflow-hidden rounded-2xl border-2 border-fx-gray">
          <div className="flex items-center justify-between bg-fx-blue px-4 py-2 text-primary-foreground">
            <h2 className="font-extrabold">{c.title}</h2>
            <span className="rounded-full bg-white/25 px-2 text-sm font-extrabold">{c.count}</span>
          </div>
          <p className="border-b-2 border-fx-gray bg-fx-gray/30 px-4 py-3 text-sm">💡 {c.tip}</p>
          <ul className="divide-y-2 divide-fx-gray">
            {c.items.map((m) => (
              <li key={`${m.lesson}-${m.activity}`} className="px-4 py-3 text-sm">
                <p className="font-extrabold">{m.prompt}</p>
                {m.given && <p className="text-fx-red-dark">✗ Você: {m.given}</p>}
                <p className="flex items-center gap-2 text-fx-green-dark">✓ Certo: {m.correct}
                  {m.type !== "match" && m.type !== "build" && (
                    <button aria-label="Ouvir" className="text-base" onClick={() => speak(m.correct)}>🔊</button>
                  )}
                </p>
                <p className="mt-1 text-muted-foreground">{m.explain}</p>
              </li>
            ))}
          </ul>
        </section>
      ))}

      <button className="btn3d btn-blue w-full" onClick={pdf} disabled={busy}>
        {busy ? "Gerando PDF…" : "📄 Baixar PDF com explicações"}
      </button>
      <Link to="/" className="btn3d btn-green w-full text-center">Continuar</Link>
    </div>
  );
}
