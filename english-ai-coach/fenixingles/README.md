# FenixInglês — conteúdo preparado fora do Lovable

O app roda no Lovable (https://fenixingles.lovable.app). Aqui fica o conteúdo escrito
antes de ir para o app, para economizar crédito: o Lovable só precisa colar o arquivo.

- `src/data/units3to8.ts` — unidades 3 a 8 (3 lições × 8 atividades cada).
- `src/data/units.ts` — cópia dos tipos do app (só para validar aqui).
- `validate.mts` — confere respostas, opções e formato:
  `node --experimental-strip-types validate.mts`
